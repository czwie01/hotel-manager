# Security Policy

Please do **not** report security vulnerabilities in public issues, pull requests, or discussions.

Use GitHub's **Private vulnerability reporting** for this repository:

1. Open the repository's **Security and quality** area.
2. Open **Advisories**.
3. Choose **Report a vulnerability**.

Include enough information to reproduce and assess the issue, but do not publish exploit details publicly before the report has been reviewed.

If GitHub's private reporting control is unexpectedly unavailable, contact the repository owner privately through their GitHub profile rather than opening a public vulnerability issue.
